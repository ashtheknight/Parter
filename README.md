# Parter
Parter - Parts + Counter.   Parter is a a parts counter as simple as that but still something I desperately need.
<img width="346" height="957" alt="image" src="https://github.com/user-attachments/assets/184c4156-e1fd-4cd6-ba10-85da31f3053e" />


Parter is simple in design but well though out it has an inset section where it stops multiple pieces from going through the ir sensor section so that part are correctly counted

Parter features 5 main parts:

The Funnel:
the funnel is the first part it allows parts to go into the next section easily, And/or allows to pile up parts 
<img width="1003" height="928" alt="image" src="https://github.com/user-attachments/assets/770c74c7-43be-438c-ada8-e2a63175fc41" />

Zig Zag Thingy:
the "Zig Zag Thingy is meant to slow down the parts so that the ir sensor count accurately 
<img width="1161" height="939" alt="image" src="https://github.com/user-attachments/assets/c4e5b055-ffcf-4e17-874a-a9adb7279cdd" />

The inset holder: 
the insert holder allows the part at any size to go through one at a time custom insets can be made at any time
<img width="1182" height="972" alt="image" src="https://github.com/user-attachments/assets/b6c64466-fcfe-4135-aca0-7f10ff75e335" />

Ir sensor section:
This is the section where the parts are counted using an ir sensor
<img width="1105" height="957" alt="image" src="https://github.com/user-attachments/assets/e41e491d-9fc3-4517-b684-404e94a386a1" />

Dropping Section:
This allows the bottom where the parts come out to be elevated and a container to be placed underneath for collection
